# 🎮 Python Quiz Game

A beginner-friendly command-line quiz game built with Python. The game tests the user's knowledge of basic computer hardware through four questions and keeps track of the final score.

## ✨ Features

- Interactive command-line interface
- User-controlled game start
- Four computer hardware questions
- Case-insensitive answer checking
- Score tracking
- Final score display
- Reusable question function
- No third-party Python packages required

## 🧠 Questions Covered

- **CPU** — Central Processing Unit
- **GPU** — Graphics Processing Unit
- **RAM** — Random Access Memory
- **PSU** — Power Supply Unit

## 🛠️ Technologies

- Python 3
- Python standard library
- Command-line interface

## ⚙️ Requirements

- Python 3.9+ recommended
- No external dependencies

## 🚀 Installation

```bash
git clone https://github.com/YOUR_USERNAME/python-quiz-game.git
cd python-quiz-game
```

No additional packages are required.

## ▶️ Run

```bash
python src/quiz_game.py
```

On some systems:

```bash
python3 src/quiz_game.py
```
